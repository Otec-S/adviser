# CLAUDE.md

Этот файл содержит рекомендации для Claude Code при работе с кодом в этом репозитории.

## Обзор проекта

Сайт юридического центра «Эдвайзер», собираемый статическим генератором **Eleventy (11ty)**. Контент и вёрстка разделены: HTML-шаблоны (Nunjucks) переиспользуют общий layout, данные (клиенты, новости, контакты) вынесены в JSON.

**Ключевые характеристики:**
- Eleventy 3.x, шаблоны на Nunjucks (`.njk`)
- Семантическая разметка, BEM (Block Element Modifier) методология
- Адаптивный макет (брейкпоинты 900px и 600px, без фиксированной min-width)
- Кастомный шрифт Jura (4 начертания через один `font-family: 'Jura'` + `font-weight`)
- Изображения оптимизируются на сборке через `@11ty/eleventy-img` (WEBP + responsive `srcset`, `loading="lazy"`)
- Контент на русском языке
- Без клиентского JavaScript

## Разработка

```bash
npm install       # первый раз
npm start         # локальный сервер с live reload (http://localhost:8080)
npm run build     # финальная сборка в _site/
```

**Страницы и навигация:**
- Пункты меню и активная страница задаются один раз в `src/_data/site.json` (поле `nav`) и `key` в front matter каждой страницы — не нужно вручную редактировать `<nav>` на каждой странице.
- Layout автоматически проставляет `aria-current="page"` и класс `nav__title_active`.
- URL страниц — «красивые»: `/about/`, `/news/` и т.д. (Eleventy создаёт `about/index.html`).

## Архитектура CSS (BEM методология)

- `.block__element` – дочерние элементы блока
- `.block_modifier` / `.block__element_modifier` – вариации
- Цвета вынесены в CSS-переменные в `:root` (`--color-dark-grey`, `--color-teal`, `--color-teal-accessible` и т.д.) — используйте их вместо литералов `rgb(...)`.
- `--color-teal-accessible` — затемнённый вариант бирюзового для текста на светлом/белом фоне (обеспечивает контраст ≥ 4.5:1, WCAG AA). Исходный `--color-teal` — только для крупных декоративных заливок, не для текста на белом.

**Основные блоки:**
- `.page` – root-контейнер с flex-макетом
- `.header` – sticky-заголовок с названием центра и навигацией
- `.nav` – навигационные ссылки
- `.content` – основная область контента; модификатор `.content_layout_column` — для страниц с вертикальным layout (о центре, услуги, новости, клиенты)
- `.card` – переиспользуемые карточки на главной, темы: `.card_theme_dark-grey`, `.card_theme_light-blue`, `.card_theme_grey`, `.card_theme_white`
- `.footer` – подвал; год копирайта подставляется автоматически (`buildYear` из `eleventy.config.js`)

## Изображения

Все `<img>` в шаблонах вставляются через shortcode `{% image "file.png", "alt текст", "css-класс", "sizes", [ширины] %}` (см. `eleventy.config.js`). Он автоматически:
- конвертирует в WEBP с fallback в исходный формат,
- генерирует несколько размеров под `srcset`,
- добавляет `loading="lazy"` и `decoding="async"`.

Исключение — `building.jpg`, используемый как CSS `background-image`: он копируется как есть через passthrough copy, без обработки.

**Добавление изображения:** положите файл в `src/images/` с понятным именем в нижнем регистре латиницей без пробелов (например, `client-name.png`) и используйте shortcode `{% image %}` в шаблоне.

## Шрифты и типография

`@font-face` в `src/styles/styles.css` объявляет одно семейство `'Jura'` с четырьмя начертаниями через `font-weight` (300/400/500/700) — используйте `font-weight`, а не отдельные `font-family` для разных насыщенностей.

## Частые задачи

**Добавление новости:**
1. Добавьте объект `{ "date": "...", "image": "...", "alt": "...", "text": "..." }` в `src/_data/news.json`.
2. Положите изображение в `src/images/`.
3. Пересоберите (`npm start` покажет изменения сразу).

**Добавление клиента:**
1. Добавьте объект `{ "logo": "...", "name": "...", "alt": "..." }` в `src/_data/clients.json`.
2. Положите логотип в `src/images/`.

**Добавление новой страницы:**
1. Создайте `src/new-page.njk` с front matter (`layout: layout.njk`, `title`, `description`, `key`, при необходимости `contentModifier: content_layout_column`).
2. Добавьте пункт в `nav` в `src/_data/site.json` — он появится в меню на всех страницах автоматически.

**Стилизация нового компонента:**
1. Определите имя блока по BEM (например, `.article`).
2. Используйте `.block__element` для дочерних элементов и модификаторы вместо отдельных классов.
3. Используйте существующие CSS-переменные для цветов; при необходимости нового цвета — добавьте переменную в `:root`.

## Рекомендации для будущей разработки

- **Язык:** весь контент на русском; сохраняйте это на новых страницах.
- **Адаптивность:** проверяйте страницы на 375/768/1440 px — есть медиазапросы на 600px и 900px.
- **Доступность:** сохраняйте `aria-current`, `:focus-visible`, alt-тексты с содержательным описанием (не «Портрет X», а «Имя Фамилия, должность»), контраст текста ≥ 4.5:1.
- **SEO:** у каждой страницы должны быть уникальные `title` и `description` в front matter.
- **Изображения:** не добавляйте `<img>` напрямую — используйте shortcode `{% image %}`.
