Этот файл содержит рекомендации для Claude Code при работе с кодом в этом репозитории.

## Обзор проекта

Статический HTML/CSS сайт юридической фирмы "Эдвайзер". Проект состоит из нескольких взаимосвязанных HTML-страниц с общей стилизацией.

**Ключевые характеристики:**
- Ванильный HTML5 + CSS (без инструментов сборки и фреймворков)
- Семантическая разметка с использованием BEM (Block Element Modifier) методологии
- Адаптивный макет (min-width: 1100px, max-width: 1600px)
- Кастомные шрифты семейства Jura
- Контент на русском языке
- Без JavaScript-зависимостей (пока)

## Разработка

**Для просмотра сайта:**
- Просто откройте `index.html` в браузере, или
- Используйте расширение Live Server в VS Code: правый клик по HTML-файлу → "Open with Live Server"

**Страницы и навигация:**
- Основная навигация повторяется в `<header>` каждой страницы
- Активная ссылка помечена классом `nav__title_active`
- Внутренние ссылки используют относительные пути (`./about.html`, и т.д.)
- Одна ссылка на аналитику пока является заглушкой (`href="#"`)

## Архитектура CSS (BEM методология)

Стилист следует BEM-соглашениям:
- `.block__element` – дочерние элементы блока
- `.block_modifier` или `.block__element_modifier` – вариации

**Основные блоки:**
- `.page` – root контейнер с flex-макетом
- `.header` – sticky заголовок с названием фирмы и навигацией
- `.nav` – навигационные ссылки
- `.content` – основная область контента (flex-макет)
- `.card` – переиспользуемые карточки контента с несколькими вариантами тем
  - `.card_theme_dark-grey`, `.card_theme_light-blue`, `.card_theme_grey`, `.card_theme_white`
- `.footer` – подвал с копирайтом

**Важно:** При добавлении новых стилей соблюдайте BEM структуру и используйте модификаторы темы (`.card_theme_*`) для вариаций цветов вместо встроенных стилей.

## Шрифты и типография

Кастомные шрифты загружаются через `@font-face` в `styles.css`:
- `Jura Bold`, `Jura Light`, `Jura Medium`, `Jura Regular`
- Файлы в формате WOFF находятся в папке `fonts/`
- При перемещении файлов проверяйте относительные пути из расположения `styles.css`

## Семантическая разметка

На всех страницах используются семантические HTML-элементы:
- `<header>`, `<main>`, `<footer>` для структуры страницы
- `<nav>` для навигации
- `<section>` для разделов контента
- `<h1>`–`<h6>` для заголовков (иерархия соблюдается)
- `<ul>/<li>` для списков (используются в макетах карточек)
- Соответствующие `aria-*` атрибуты для доступности

При редактировании или создании контента сохраняйте семантическую структуру.

## Частые задачи

**Добавление новой страницы:**
1. Создайте новый `.html` файл с заголовком, навигацией и подвалом из существующей страницы
2. Обновите тег `<title>`
3. Добавьте класс `nav__title_active` к ссылке текущей страницы
4. Добавьте ссылку на новую страницу во все существующие меню навигации
5. Структурируйте контент используя компоненты `.card` или семантические разделы

**Стилизация нового компонента:**
1. Определите имя блока по BEM (например, `.article`)
2. Используйте `.block__element` для дочерних элементов
3. Для вариаций используйте `.block__element_modifier` вместо отдельных классов
4. Смотрите `styles.css` для существующих значений цветов (используйте RGB значения как они написаны)

**Обновление изображений:**
- Размещайте изображения в папке `images/`
- Имена файлов должны быть описательными (например, `adviser-news.png`, имена клиентов)
- Обновляйте ссылки в HTML, используя относительные пути (`./images/filename.png`)
